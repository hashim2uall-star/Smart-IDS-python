# Simple IDS - Intrusion Detection System

## الوصف
مشروع بسيط بلغة بايثون لكشف محاولات الدخول الفاشلة المتكررة.
البرنامج بقرا ملف `log.txt` وبيفتش لو في IP حاول يدخل اكتر من 3 مرات فاشلة.
لو لقى بيعمل Alert في ملف `report.txt`

## الملفات الموجودة
1.  `ids.py` : الكود الرئيسي للبرنامج
2.  `log.txt` : ملف سجلات الدخول فيهو محاولات ناجحة وفاشلة
3.  `report.txt` : ملف التقرير البطلع فيهو التنبيهات
4.  `README.md` : ملف الشرح دا

## طريقة العمل
1.  البرنامج بقرا كل سطر في `log.txt`
2.  بفتش كلمة "FAILED" وبياخد ال IP
3.  لو نفس ال IP اتكرر 3 مرات او اكتر بيعتبرو هجوم Brute Force
4.  بكتب النتيجة في `report.txt`
